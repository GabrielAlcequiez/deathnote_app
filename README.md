# Death Note: El Cuaderno

Aplicación Android académica dedicada al anime original de Death Note. Experiencia visual de libreta oscura, contenido sobre personajes y momentos, videos integrados y el juego «Ryuk y las manzanas».

## Estado del proyecto

**Fase actual: Tasks. Specification y Plan aprobados; desglose de tareas redactado y pendiente de aprobación.**

La base existente es un proyecto Android de Kotlin con Jetpack Compose. Todavía no se ha implementado la aplicación descrita en estos documentos.

## Convenciones

El código y los mensajes de commit se escribirán en inglés. La interfaz se mostrará en español; los comentarios y la documentación pueden escribirse en español. Véase [CONTRIBUTING.md](CONTRIBUTING.md).

Remoto solicitado: `git@github.com:GabrielAlcequiez/deathnote_app.git`.

## Flujo de trabajo acordado

Specification → Plan → Tasks → Implementation → Verification.

Cada cambio de fase requiere aprobación expresa del usuario. Aprobar la especificación habilita únicamente la fase Plan. Los documentos se mantendrán actualizados conforme se aprueben decisiones o cambios de alcance.

Specification y Plan están aprobados. Tasks se presenta para revisión. El código de la aplicación se escribirá en Implementation, una vez aprobadas las fases anteriores. La ejecución y los resultados de las verificaciones se documentarán en Verification; los criterios actuales no constituyen pruebas realizadas.

## Entrega prevista

APK instalable para Android, con un plazo comunicado de tres días desde el inicio del trabajo. Las fotos, videos y datos personales podrán sustituirse desde el proyecto. La aceptación completa de fotos y reproducción de los tres momentos requiere que el usuario proporcione esos recursos.
